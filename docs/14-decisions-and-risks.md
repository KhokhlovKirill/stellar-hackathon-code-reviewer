# 14 — Решения (ADR), развилки, риски

## 1. ADR — принятые решения

| ADR | Решение | Почему | Альтернатива / откат |
|---|---|---|---|
| ADR-1 | Язык — **Python** | Прямой приоритет в task.md; экосистема Semgrep/детект/LLM-клиентов | Go/Node допустимы по условиям; откат дорогой — фиксируем Python |
| ADR-2 | **Гибрид**: детерминированный слой + LLM-ансамбль + judge | Рынок показывает: чистый LLM = низкая security-точность; детерминированное ядро = near-zero-FP и страховка дорогих C1-критериев при отказе LLM | Чисто-LLM (отвергнут: FP/recall) |
| ADR-3 | **Semgrep OSS** как детерминированный SAST | Индустриальный taint-анализ, низкий FP, десятки языков, offline-рулсеты | Свой regex-движок (слабее), CodeQL (тяжёл/лицензия) |
| ADR-4 | **Arq + Redis** как очередь | asyncio-native под FastAPI+httpx+LLM I/O, ретраи, отложенные задачи | Celery (мощнее, но sync-центричен) — задокументирован как замена |
| ADR-5 | Абстракция `VCSProvider`, 3 реализации | Условие задачи — GitHub/GitLab/Bitbucket; единый pipeline | По-провайдерные форки (отвергнуто: дублирование) |
| ADR-6 | Блокировка merge = **падающий required status-check**, не hard-deny | Постановка: блокирует бот, разблокирует тимлид; не ломает git-флоу | Прямой запрет API (грубо, не переносимо между провайдерами) |
| ADR-7 | Дообученная `don-agent-v3` — **тир за флагом**, дефолт по eval | Принцип «метрики до интуиции»: включаем в дефолт, только если доказан uplift на golden-set | Жёстко всегда вкл. (отвергнуто: непроверяемо) |
| ADR-8 | Без dynamic analysis / запуска кода из PR | PR — недоверенный вход, исполнение = RCE-вектор | Sandbox-исполнение — вне scope, отдельный риск-проект |
| ADR-9 | Diff трактуется как **данные**, вывод модели не управляет policy | Защита от prompt-injection через содержимое PR | — |
| ADR-10 | React SPA (`frontend/`) + nginx в Docker | Единый UI на :8099, REST `/api` | Legacy Jinja удалён (2026-05) |
| ADR-11 | Дообучение в scope **не входит**; данные mythos — только eval/fixtures/few-shot | Модель уже готова; задача — сервис, а не тренинг | `review.lora` на PrimeVul-as-diff — roadmap-усиление |

## 2. Открытые развилки (решаются по ходу, фиксируются как ADR)

- **OpenRouter judge-модель по умолчанию** — выбрать по eval (баланс качество/стоимость);
  до получения ключа организаторов слот конфигурируемый.
- **Профиль ансамбля по умолчанию** — `det+cloud+don` vs `det+don+judge`: решает eval-
  прогон (`12 §4`).
- **Bitbucket Cloud webhook без HMAC** — секрет-в-URL + IP-allowlist; при доступности
  Bitbucket DC — перейти на HMAC. Зафиксировать по среде заказчика.

## 3. Риски и контрмеры

| Риск | Вероятность | Влияние | Контрмера |
|---|---|---|---|
| SSD не примонтирован / LM Studio не поднят | Высокая (сейчас так) | Сред. | Авто-fallback на cloud + детерминированный слой; деградация видна в метриках, не падение |
| Дообученная модель дрейфует в CTF-формат | Сред. | Низк. | Override-промпт + repair-парсер + judge-нормализация; eval-контроль |
| Высокий FP отпугивает разработчиков | Сред. | Высок. | Judge-анти-FP слой, confidence-гейтинг, FP-rate как KPI и регресс-гейт |
| Prompt-injection из PR | Сред. | Высок. | Diff = данные; вывод не исполняется; judge игнорирует инструкции из контента |
| Лимиты/стоимость OpenRouter на хакатоне | Сред. | Сред. | Бюджеты per-scan, кэш, детерминированный слой снимает часть нагрузки, локальные тиры |
| Большие PR / шторм пушей | Сред. | Сред. | Map-reduce, отмена устаревших head_sha, per-repo конкуррентность, backpressure |
| Утечка токена/секрета в лог | Низк. | Критич. | Vault + redaction-фильтр + тест «grep логов на секреты» в `12 §6` |
| Расхождение маппинга строк между провайдерами | Сред. | Сред. | Контрактные тесты на каждый провайдер + golden в 3 payload-форматах |
| Python 3.14 на хосте vs 3.12 в образе | Низк. | Низк. | Рантайм фиксируется образом; хост-версия не влияет |

## 4. Точки отката

- LLM полностью недоступен → публикуем только детерминированные находки (C1/C3 закрыты).
- Дообученная модель не даёт uplift → профиль `det+cloud+judge`, ADR обновляется.
- Bitbucket-инлайн не матчится → file-level комментарий с явной строкой (не теряем находку).
- Очередь/Redis недоступны → `api` отвечает 503 на webhook (провайдер ретраит сам),
  данные не теряются.
